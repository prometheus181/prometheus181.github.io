5 free tools to un-slop your AI website designs
1 impeccable github.com/pbakaus/impeccable
Removes the default Claude-looking features you find on every site.
npx impeccable install
2 awesome design github.com/VoltAgent/awesome-design-md
Lets Claude recreate any site with the exact same fonts, colors and spacing.
copy a site's DESIGN.md from getdesign.md into your project
3 web design guidelines github.com/vercel-labs/agent-skills
Finds and fixes every broken button, form and mobile layout.
npx skills add vercel-labs/agent-skills --skill web-design-guidelines
4 chrome devtools mcp github.com/ChromeDevTools/chrome-devtools-mcp
Checks your site's load speed and makes everything load faster.
claude mcp add chrome-devtools -- npx chrome-devtools-mcp@latest
5 image to three.js github.com/img2threejs/img2threejs
Turns any static photo into a 3D object you can spin around.
npx --yes img2threejs@latest install
