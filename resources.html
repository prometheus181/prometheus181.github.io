5 free tools that turn Claude into a designer
1 impeccable github.com/pbakaus/impeccable
Scans every UI file Claude creates so you stop getting AI slop.
npx skills add pbakaus/impeccable
2 web design guidelines github.com/vercel-labs/agent-skills
Audits your code against Vercel's design rules before you ship.
npx skills add vercel-labs/agent-skills --skill web-design-guidelines
3 chrome devtools mcp github.com/ChromeDevTools/chrome-devtools-mcp
Claude opens Chrome, screenshots what it built and reads the errors for you.
claude mcp add chrome-devtools -- npx chrome-devtools-mcp@latest
4 awesome design github.com/VoltAgent/awesome-design-md
Design systems from real websites, so Claude copies their type, spacing and layouts.
copy one site's DESIGN.md into your project
5 image to code github.com/Leonxlnx/taste-skill
Give Claude a screenshot of any site and it rebuilds it in real code.
npx skills add https://github.com/Leonxlnx/taste-skill --skill image-to-code
